# Lumesix - Smart Subscription Insights

**AI-Powered Analytics for Mobile App Subscriptions**

*RevenueCat Shipaton 2025 Hackathon Submission*

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- React Native development environment
- iOS Simulator / Android Emulator
- RevenueCat account

### Project Structure
```
lumesix/
├── lumesix/              # React Native mobile app
├── lumesix-backend/      # Node.js API server
├── docs/                 # Documentation
├── progress.txt          # Development progress tracker
└── project-overview.md   # Complete project overview
```

### Development Setup

1. **Mobile App (React Native)**
   ```bash
   cd lumesix
   npm install
   npx react-native run-ios     # iOS
   npx react-native run-android # Android
   ```

2. **Backend API**
   ```bash
   cd lumesix-backend
   npm install
   npm run dev
   ```
